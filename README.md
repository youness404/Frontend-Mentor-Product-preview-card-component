## Overview

This repository contains my solution for the Product Preview Card component challenge from Frontend Mentor.  
The goal was to build a responsive card component that displays product information, using only HTML and CSS.

## Built With

- HTML5
- CSS3
- [Frontend Mentor Challenge](https://www.frontendmentor.io/challenges/product-preview-card-component-GO7UmttRfa)

## Getting Started

To view the project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/youness404/Frontend-Mentor-Product-preview-card-component.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Frontend-Mentor-Product-preview-card-component
   ```
3. **Open `index.html` in your browser.**

No additional dependencies are required.
